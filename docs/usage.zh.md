# 使用

[English](usage.en.md) · [安装](../README.md)

本地 Qwen3-ASR MLX 需要 Apple Silicon macOS 和可发现的 Python 3.10+。在设置 → 语音识别 → 识别中选择 `1.7b-8bit`（默认）或 `0.6b-8bit`，点击安装 / 下载。首次安装需要访问 PyPI 和 Hugging Face。Host 管理独立环境及允许的模型权重；推理在本地执行，无需单独服务器或监听端口。

点击 Composer 麦克风或按 `Ctrl+Shift+Space` 开始/停止。识别栏显示进度和波形；停止会完成识别，丢弃会取消正在转写的任务。Escape 结束语音任务并保留已接受的草稿供检查。编辑草稿后手动发送，引用片段和人工修改由用户控制。

## 设置

| 分组 | 选项 |
| --- | --- |
| 通用 | 快捷键开关与组合、提示音、录音上限（1–600 秒，默认 120） |
| 识别 | Qwen 模型、空闲卸载（1–1440 分钟，默认 60）、上下文提示（最多 1024 字符）、模型与运行环境管理 |
| 关于 | 版本、许可证、DSH 兼容范围、本 fork 安装与更新说明 |

合法字段短暂延迟后或失焦时独立保存。无效草稿保持可见，不阻止其他合法字段保存；保存失败会保留修改。空提示词表示不施加模型偏置，可用提示词引导输出文字体系或领域词汇。

模型控制支持取消下载、删除权重、预加载和手动卸载。活动会话期间不能卸载或删除。最后一个会话结束后的空闲 TTL 释放模型内存并保留权重，下次录音自动重新加载。

## 限制与证据

其他平台无法运行 MLX worker。产品不提供其他识别后端或文本润色。模型质量与延迟取决于硬件和录音条件。Desktop/麦克风及 M4 Max 集成验收尚未完成，自动化和组件检查不能代替该结果。
