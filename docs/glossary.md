# Glossary

- **Host**: DSH process owning settings, model setup, and the Qwen worker.
- **Client**: Browser or Desktop web renderer capturing audio and displaying drafts.
- **MLX**: Apple Silicon inference framework used by local Qwen3-ASR.
- **PCM16**: Signed 16-bit audio sent in ordered mono 16 kHz chunks.
- **Prefix Rollback**: Qwen streaming revision that can shorten an earlier hypothesis.
- **Idle TTL**: Time after the last session closes before model memory is released; downloaded weights remain.
- **Voice span**: Revision-guarded insertion owned by one recording within the editable Composer.

Historical provider terminology remains in the decision archive and optional research.
