# Contributing

Read [AGENTS](AGENTS.md) for the development contract and [development](docs/development.md) for setup, local loading, and validation. Current architecture and open work are indexed in [docs](docs/README.md).

This is the [iBobbyTS/dsh-ears fork](https://github.com/iBobbyTS/dsh-ears) of [WizisCool/dsh-ears](https://github.com/WizisCool/dsh-ears). Report fork-specific issues to this repository; do not direct its users to upstream installation or release channels. Preserve upstream attribution and historical ADRs.

Describe the intended outcome, bounded scope, and validation evidence for a contribution. Keep unrelated work separate. Public reports must omit recordings, transcripts, credentials, and exploit details; see [SECURITY](SECURITY.md). Release actions require the maintainer's authorization for this fork and target.
